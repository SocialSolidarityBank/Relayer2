# 열람 기록 보기 — 인터뷰 결과 (2026-09-16 Q)

`ooo interview` Path B(Ouroboros MCP 없음 — 대화 맥락이 정본이고 세션은 남지 않는다).
여섯 제품을 실제로 열어 본 레퍼런스 조사와 운영 실측을 근거로 삼았다.

## 한 문장

> 기관 관리자가 지난 30일을 기본으로 열람 기록을 보되, 맨 위에 숫자와 눈여겨볼 것
> (담당 아닌 열람·내려받기)을 **판정 없이 세어** 주고, 기간·사람·행위 종류·글자로 좁히며,
> 한 줄을 누르면 그 사람이나 당사자로 좁혀 조사를 잇고, 보이는 그대로 CSV 로 내린다.
> 기록은 3년 둔다.

## 왜 필요한가 — 실측

2026-09-16 운영(실무자 2명 · 사례 9건 · 하루):

```

  열람          116줄 (91%)
    15초 다시보기  75
    당사자 정보    37
담당 아닌 열람   112건 / 112건   ← 대부분 미배정 탓
밤 10시~7시 열람   1건
```

실무자 5명·사례 50건이면 하루 1,500줄 안팎이다. 지금의 `최근 200건 한 덩어리`는
그 규모에서 **반나절치도 못 담는다.**

|---|---|---|---|---|

공통으로 확인된 것:

1. 정보 순서는 **`행위자 → 행위 → 대상 → 시각`** 으로 사실상 통일. 정렬은 전부 최신순.
2. **기간 · 행위자(또는 대상) · 행위 종류** 필터가 공통 기본.
3. 상세는 인라인 펼침 아니면 우측 패널 — **별도 페이지로 빠지는 제품은 하나도 없다.**
4. 반복 접기는 Vercel 하나뿐. 우리는 이미 10분 접기를 넣어 앞서 있다.
5. 보관 기간이 명시된다(30~365일). 우리는 무제한이었다.

## 정한 것

### 1. 두 층이다

`숫자` → `눈여겨볼 것` → `목록과 필터`. 정기 점검은 위에서 끝나고, 사고 추적은 아래로 내려간다.

### 2. 판정하지 않는다

제품은 **세기만 하고 판단은 사람이 한다.** `담당 아닌 열람 9건`은 사실이고
`의심스러운 접근 9건`은 판정이다. 앞엣것만 쓴다. `의심`·`위험`·`경고`를 쓰지 않는다.

불일치 기능과 같은 규율이다 — *"판정하지 않는다. 달라졌다는 사실만 낸다."*

세는 것 둘:
- **담당 아닌 당사자를 열었다** — 상담 기록은 맡은 사람만 보는 것이 원칙이다
- **문서·녹음을 가져갔다** — 화면으로 본 것과 파일로 내려받은 것은 다르다. 내려받기는 기관 밖으로 나간 것이다

시간대(야간)와 열람 횟수는 **세지 않는다.** 기관마다 근무 형태가 달라 오탐이 많고,
횟수는 10분 접기가 이미 걷었다.

### 3. 필터 넷

`기간`(기본 지난 30일) · `사람` · `행위 종류`(열람·기록·운영) · `글자 검색`.

**이름 검색은 서버가 못 한다** — 이름은 금고 암호문이다. 불러온 것 안에서만 걸러진다.
당사자 목록이 같은 제약을 이미 안고 있다.

### 4. 한 줄을 누르면 좁힌다

상세 패널을 만들지 않는다. **그 사람 것만** 또는 **그 당사자 것만** 으로 좁혀
조사를 잇는다 — Slack 의 `Show User's Logs Only` 와 같은 자리다.
한 줄에 이미 다 적혀 있어 더 펼칠 것이 없고, 관리자가 실제로 하는 다음 행동은
"더 자세히"가 아니라 "이 사람 것 전부"다.

### 5. 내보내기는 고르게 한다

`이름 포함`(기관 내부 보관용) / `가명만`(외부 제출용) 둘 중에 고르고,
**어느 쪽으로 내렸는지가 열람 기록에 남는다.**

화면 그대로 내리면 금고에 넣어 둔 이름이 평문 파일로 기관 밖에 나가고, 그 파일에는
우리 보유기간도 삭제 장치도 닿지 않는다. 자유는 두되 그 선택이 기록에 남는다.

### 6. 3년 둔다

기록보다 길게 잡는다(음성·문서·서면은 1년). **사고는 늦게 발견된다** — 기록은 지워도
누가 봤는지는 남긴다. 3년이 지난 줄을 실제로 지우는 장치가 필요하다(`voice.sweep` 꼴).

## 아직 안 정한 것

- **페이지 나누기.** 30일이면 규모에 따라 수천 줄이다. 무한 스크롤인지 더 보기인지 미정.
- **3년 삭제 장치.** 언제 누가 돌리나(정기 작업? 관리자 버튼?).
- **당사자 본인에게 보여줄 것인가.** 이번 범위 밖으로 뺐다.
- **외부 제출 서식.** CSV 로 정했지만 상위기관이 정한 서식이 있으면 거기 맞춰야 한다.
