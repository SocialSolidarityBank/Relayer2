# 관문 2 측정지

## 관문 2 결과

> **정성 결과: 재사용 의사가 분명해 관문 2의 사람 검증 근거를 확보했다.**

- **참여자:** 익명 실무자 4명(실무자 A, 실무자 B, 실무자 C, 실무자 D)
- **사용 범위:** 각 실무자가 동일한 흐름을 **2회차까지** 사용했다.
- **재사용 의사:** 4명 모두 다음에도 사용하겠다는 의사를 분명히 보였다.
- **설문 수집:** 설문 응답은 **Google Sheets**에 수집했다.
- **정량 결과 보류:** 필수 입력 수, 실제 입력 수, 소요 시간, 진행자 도움 횟수, 현행 CCC 베타와의 비교 결과는 **Q가 제공할 시트 링크를 받은 뒤** 기입한다. 링크를 받기 전에는 수치나 비교 결과를 추정하지 않는다.

위 결과는 익명화한 질적 관찰 기록이다. 정량 비교 기준을 포함한 최종 판정표는 Q의 Google Sheets 링크가 확보된 뒤 갱신한다.

- 시나리오: `docs/beta-scenario.md`
- 참가자 표기 원칙: 실명·소속을 적지 않고 `실무자 A`처럼 적는다.

## 미래·참고용 측정 템플릿

아래 양식은 후속 측정이나 정량 결과를 기록할 때 사용한다. 참여자별로 복사하되, 이름은 계속 익명 표기를 사용한다.

### 진행자 준비

```bash
cd <repository-directory>
./scripts/reset-for-measure.sh             # 참가자가 바뀔 때마다 실행한다. 메모가 남아 있어도 즉시 초기화된다
```

측정 전에는 참가자 브라우저를 새 창이나 시크릿 창으로 열어 진행자의 로그인 상태가 남지 않게 한다. 필요하면 브라우저 콘솔에서 `docs/measure.js`를 실행하고, 측정이 끝난 뒤 `relayer측정.끝()`을 호출한다. 측정 중에는 새로고침하지 않는다.

### 미리 말해 주는 것

AI 정리는 상담을 저장한 뒤 `당사자 정보 › 회차별 요약 › AI 정리`에서 사용할 수 있다. 외부 LLM·국외 처리 동의가 없으면 동의가 필요한 상태로 막히는 것이 정상이다. 녹음·STT나 경과 리포트처럼 별도 설정이 필요한 기능은 실제 측정 범위에 포함했는지 먼저 기록한다.
