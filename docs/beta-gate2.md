## 진행자 준비 (측정 직전 5분)

```bash
cd <repository-directory>
./scripts/reset-for-measure.sh --mini     # 참가자가 바뀔 때마다. reset 이라고 적어야 진행된다
```

**참가자에게 주는 것은 주소 한 줄이다.**

```
https://relayer.kr/test                    (공개 베타 주소)
```

계정 `test2` / `test2`. 참가자 브라우저는 **새 창이나 시크릿**으로 연다 — 진행자의 로그인이 남아 있으면
로그인 화면을 못 보고 시작한다.

계수기: 참가자 브라우저 콘솔에 `docs/measure.js` 를 붙여 넣고, 끝나면 `relayer측정.끝()`.
**측정 중에는 새로고침하지 않는다** — 계수기가 사라진다.

### 미리 말해 주는 것 (말 안 하면 "고장"으로 기록된다)

AI 정리는 **있다**. 상담을 저장한 뒤 `당사자 정보 › 회차별 요약 › AI 정리` 에서 쓴다.
다만 **동의를 받아야 돌아간다**(외부 LLM·국외 처리). 동의 없이 누르면 막히는 것이 정상이다.
녹음·STT 는 아직 없다. 경과 리포트도 없다.
