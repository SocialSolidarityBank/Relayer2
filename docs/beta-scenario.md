- 작성일: 2026-09-14
- 쓰임: 실무자 한 명을 앉혀 놓고 그대로 읽어 주면 되는 대본. 관문 2(`PLAN.md` §1) 측정은 이 시나리오로 한다.
- 측정지는 `docs/beta-gate2.md`에 적는다.
- **합성 자료만 쓴다.** 실제 당사자 이름·연락처·사연을 넣지 않는다.

## 0-A. 누구를 어떻게 앉히나

**필요한 사람은 1명, 필요한 시간은 30분.** 두 명이면 더 좋지만 한 명으로도 판정한다(같은 자리에서 두 명이 막히면 1순위, 한 명만 막히면 기록만).

| 후보 | 장점 | 주의 |
|---|---|---|
| 사회연대은행 상담 실무자 | 진짜 사용자. 현행 CCC 와 비교가 가능하다 | 일정 잡기가 가장 어렵다. 실데이터를 꺼내지 않도록 대본을 먼저 보여 준다 |
| 사회복지 경력이 있는 내부 인력 | 섭외가 빠르다 | 현행 CCC 를 안 써 봤으면 비교값이 빠진다 → 종이·엑셀 기준으로 대신 적는다 |
| 상담 경험이 없는 동료 | 오늘 바로 가능 | 관문 2 판정에는 못 쓴다. 대본이 도는지 보는 예행연습용 |

**권하는 순서**: 예행연습 1회(아무나, 15분) → 실무자 본 측정(1~2명, 각 30분).
예행연습에서 대본이 막히는 자리를 먼저 지우면 본 측정 30분이 낭비되지 않는다.

### 30분 짜임

| 분 | 하는 일 |
|---|---|
| 0–3 | 참가자에게 하는 말(§1) + 지금 안 되는 것(§5) 읽어 주기 |
| 3–5 | 참가자 브라우저에 계수기 붙여 넣기(아래) |
| 5–15 | 대본 A — 새 당사자, 첫 상담까지 |
| 15–17 | 15초 판정(§3-1) — 다시보기 15초 보여 주고 덮은 뒤 질문 |
| 17–25 | 대본 B — 2회차 기록 |
| 25–30 | 끝나고 묻는 것(§3-5) + 계수기 결과 옮겨 적기 |

**비교군(현행 CCC)은 같은 사람에게 다른 날 재지 않는다.** 같은 자리에서 대본 B 를 양쪽에서 한 번씩 돌린다. 순서 효과를 줄이려면 사람마다 순서를 바꾼다(A 는 릴레이어 먼저, B 는 CCC 먼저).
현행 CCC 에 접속할 수 없으면 비교값 칸에 **`지금 쓰는 방식(종이·엑셀) 기준`** 이라고 적고 그대로 진행한다. 비교 대상이 없다고 측정을 미루지 않는다.

## 0-B. 준비 (진행자가 미리)

```bash
cd ~/DEVELOPER/PROJECTS/RELAYER2
docker compose up -d
set -a && . ./.env && set +a
node api/src/index.ts &                    # API  :8787
pnpm --dir web exec vite --host 0.0.0.0 &  # 화면 :5173 (다른 기기에서도 들어온다)

./scripts/reset-for-measure.sh             # 참가자가 바뀔 때마다 이것만 다시
```

- 접속: 진행자 맥은 `http://localhost:5173/`, **참가자 노트북은 같은 Wi-Fi 에서 `http://<맥 IP>:5173/`**
  (IP 는 `reset-for-measure.sh` 가 찍어 준다. 사내망 안에서만 열린다 — 공개 배포가 아니다.)
- 계정: `worker@relayer.test` / `relayer-beta`
- **계수기**: 참가자 브라우저에서 개발자 도구 콘솔을 열고 `docs/measure.js` 를 통째로 붙여 넣는다.
  끝나면 `relayer측정.끝()` 을 쳐서 표를 얻는다 — 채운 칸·선택·버튼·총 시간·저장 시점.
  손으로 세지 않는다. 다만 **새로고침하면 계수기가 사라지므로** 측정 중에는 새로고침하지 않는다.
- 브라우저는 새 창(또는 시크릿)으로 연다. 진행자의 이전 상태가 남아 있으면 측정이 오염된다.
- **비교군을 같은 자리에 띄워 둔다**: 현행 CCC 베타 클라이언트(관문 2의 비교 대상). 같은 대본을 양쪽에서 한 번씩 돌린다.

> 오늘 보실 건 상담 기록 도구입니다. 제가 드릴 가상의 상담 상황을 보고, **평소 상담 끝나고 기록하듯이** 넣어 주세요.
> 막히면 막힌 채로 두셔도 됩니다. 어디서 막히는지가 오늘 보려는 것이에요.

**진행자는 돕지 않는다.** 30초 이상 멈추면 그 자리를 기록하고, 60초가 지나면 그때 알려 준다. 도운 횟수도 측정값이다.

## 2. 대본 A — 새 당사자, 첫 상담까지 (예상 8~12분)

### A-1. 상황 카드 (참가자에게 종이나 화면으로 보여 준다)

> **박수경 / 010-3333-4444 / 함께온기금 울타리대출 / 6회 예정**
>
> 오늘 처음 만났습니다. 요양보호사로 일하다 어머니 간병 때문에 근무를 주 3일로 줄였고, 카드대금이 두 달 밀렸습니다. 기초생활수급은 아니고, 차상위인지는 본인도 모릅니다.
> 월세는 45만 원, 계약은 내년 3월 만료입니다. 허리 통증으로 2주에 한 번 통원 중입니다.
> "빚을 정리하고 다시 일을 늘리고 싶다"고 말했습니다.
> 다음에 만나면 **채무 내역서를 같이 보기로** 했고, **통원 주기가 정확히 어떻게 되는지**는 다음에 확인하기로 했습니다.
> 다음 상담은 **2주 뒤 오후 2시, 사무실에서 대면**입니다.

### A-2. 할 일

1. 당사자를 등록한다
2. 첫 상담 기록(인테이크)을 쓴다 — 상황 카드의 **약속(채무 내역서)과 못 물어본 것(통원 주기)** 도 적는다
3. 다음 상담 일정을 잡는다

### A-3. 진행자가 볼 것

- 어려움 영역을 **몇 개** 고르는가, 고른 뒤 열리는 세부 질문을 **끝까지 채우는가 건너뛰는가**
- `전체 상담 목표`를 비우고 넘어가는가, 채우는가
- `다음에 물어볼 것`을 스스로 찾아 쓰는가 (안 쓰면 A-4에서 물어본다)
- 차상위 여부를 모를 때 어떤 선택지를 고르는가 (`무응답`이 보이는가)
- **월세·계약 이야기를 어디에 적는가.** 화면에는 `주거`가 없고 국가 표준 이름인 **`생활환경`** 이다(희망이음·행복e음 호환). 못 찾고 헤매면 그 시간을 적는다 — 표준을 바꿀 수는 없으니 안내 문구로 풀 문제다
- 약속(`수행할 과제`)과 질문(`다음에 물어볼 것`)을 **구분해 넣는가**, 한쪽에 몰아넣는가

### A-4. 끝나고 묻는 것

- 지금 넣은 내용 중 **평소에는 안 쓰는 것**이 있었습니까?
- 평소에 쓰는데 **넣을 자리가 없던 것**이 있었습니까?

## 3. 대본 B — 2회차 기록과 다시보기 (예상 5~8분) ⭐ 핵심

**여기가 이 제품의 존재 이유를 보는 자리다.** A를 끝낸 같은 사례로 이어서 한다.
사례로 돌아가는 길을 알려 주지 않는다 — `일정`이나 `당사자 목록`에서 스스로 찾는지 본다.

### B-1. 먼저 보여 준다

`15초 다시보기`를 열고 **아무 설명 없이** 15초를 준 뒤 화면을 덮는다. 그리고 묻는다.

> 이 사람과 오늘 무슨 이야기를 해야 합니까?

말한 내용을 그대로 적는다. `확인할 과제`와 `오늘 물어볼 것`을 짚어 내면 성공이다.

### B-2. 상황 카드

> **2주 뒤, 두 번째 만남입니다.**
>
> 채무 내역서는 **아직 못 뗐다**고 합니다. 주민센터에 갔는데 서류가 하나 더 필요했답니다. 다음 주에 다시 가 보겠다고 합니다.
> 통원 이야기는 **오늘 못 물어봤습니다.**
> 대신 근무를 주 4일로 늘렸다는 이야기를 했습니다. 어머니 주간보호 신청이 통과됐다고 합니다.
> 다음에는 **채무 내역서를 같이 보기로** 다시 약속했습니다.

### B-3. 할 일

1. `상담 기록하기`에서 오늘 내용을 기록한다
2. 레일에 뜬 지난 과제·질문을 **실제 상황에 맞게** 처리한다
3. 저장한다

### B-4. 진행자가 볼 것 — 여기만은 놓치지 말 것

| 관찰 | 왜 |
|---|---|
| `채무 내역서`에 **`못 함 · 계속`** 을 누르는가 | 이 제품의 핵심 동작. 안 누르고 넘어가면 왜 안 눌렀는지 묻는다 |
| `통원 주기` 질문에 **아무것도 안 누르는가** | 못 물어본 것을 비워 두는 게 맞는 동작이다. 억지로 `확인함`을 누르면 규칙이 전달 안 된 것 |
| 저장 뒤 다시보기에서 **`지난 회차 미확인`** 을 알아보는가 | 알아보면 규칙이 화면만으로 전달된 것 |
| 같은 과제(`채무 내역서`)를 **새로 또 적는가** | `못 함 · 계속`이 곧 "계속 간다"는 뜻인데 또 적으면 확인할 과제에 같은 문구가 두 줄로 쌓인다. 두 명이 다 그러면 화면으로 막을 자리다 |
| `근무 4일로 늘림`을 **어디에 적는가** | `달라진 것`(영역: 고용)이 의도다. 메모에만 적으면 구획 이름이 안 읽힌 것 |

### B-5. 끝나고 묻는 것 (관문 2의 답)

1. 같은 상담을 **지금 쓰시는 도구**에 기록한다면, 더 손이 갑니까 덜 갑니까?
2. 다음 상담에도 이걸 쓰시겠습니까? (예 / 아니오 / 조건부 — 조건이면 무엇인지)
3. 하나만 고칠 수 있다면 어디를 고치겠습니까?

| 항목 | 재는 법 |
|---|---|
| **필수 입력 수** | 저장까지 반드시 채워야 했던 칸 수 |

## 5. 지금 안 되는 것 (참가자에게 미리 말해 준다)

말해 주지 않으면 "고장 났다"로 기록되어 측정이 오염된다.

- **AI·녹음이 없습니다.** 다시보기의 `AI 확인 안 함`은 정상 표시입니다.
- **경과 리포트가 없습니다.** 당사자 정보의 `15초 다시보기` 탭이 그 자리를 대신합니다.
- **동의서 화면이 없습니다.** 합성 자료만 쓰는 단계라 뺐습니다.
- 당사자 초대·내 정보·설정·기관 메뉴가 없습니다.
- **디자인이 미완입니다.** 라벨·간격·색은 다음 차례입니다.

## 6. 하면 안 되는 것

- 실제 당사자 이름·연락처·사연 입력 금지. 대본 밖 내용이 필요하면 **지어낸 이름**을 쓴다.
- 측정 기록에 참가자 실명을 남기지 않는다(`실무자 A`로 적는다).
- 브라우저에 로그인 상태를 남긴 채 자리를 뜨지 않는다.

## 7. 끝나고

3. DB는 그대로 둔다. 다시 깔려면 `node api/src/seed.ts`.

## 8. 예행연습 기록 (2026-09-15, 자동)

사람을 앉히기 전에 대본 A·B 를 헤드리스 브라우저로 한 바퀴 돌렸다. **대본이 실제로 도는지**만 본 것이고, 사람의 속도가 아니므로 시간은 기준이 되지 않는다.

| | 채운 칸 | 선택(라디오·체크) | 누른 버튼 |
|---|---|---|---|
| 대본 A (등록~일정) | 10 | 13 | 5 |
| 대본 B (2회차 기록) | 4 | 1 | 4 |

이 숫자는 **대본이 요구하는 최소치**다. 사람은 더 넣는다(세부 항목을 더 고르고, 지우고 다시 쓴다). 참가자 값이 이보다 크게 벌어지면 그 차이가 곧 마찰이다.

예행연습에서 잡아 고친 것:

1. **인테이크에 `수행할 과제`가 없었다.** 대본 A 의 약속("채무 내역서를 같이 보기로")을 적을 자리가 없어 2회차 레일이 비었고, 대본 B 의 핵심 관찰인 `못 함 · 계속`이 **아예 성립하지 않았다.** 칸을 만들었다.
2. **인테이크 소절 번호가 `1-2`부터 시작하고 `3-3`이 없었다.** 정본 문서의 절 번호라서 생긴 구멍인데 화면이 고장 난 것처럼 읽힌다. 번호를 화면에서 뗐다.
3. 계수기가 라디오·체크를 `채운 칸`으로 두 번 세고 있었다. 고쳤다.
