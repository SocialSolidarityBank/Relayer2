# 릴레이어 인테이크 작성하기 - 최종 수정 요청 사항

## 1. "무응답" 삭제

- 대상: 상담신청 유입경로 / 연락 가능 시간
- "해당 없음"은 유지

## 2. 맨 위에 "상담 일시와 상담 방식" 칸 추가

| 항목 | 입력 방식 |
|---|---|
| 상담 일시 | 달력에서 고르기 |
| 상담 방식 | 대면, 전화, 화상, 기타(이메일, SNS 등) 중 하나 |
| 상담 장소 | "대면"일 때만 나타나는 글 칸 |

## 3. 공적급여, 수급자 여부 바꾸기

| 항목 | 입력 방식 |
|---|---|
| 수급자 여부 | 기초생활보장수급, 차상위계층, 해당 없음 중 하나 |
| 수급 유형 | "기초생활보장수급"일 때만 나타남. 생계급여, 의료급여, 주거급여, 교육급여 중 여러 개 |
| 기타 공적급여 | 기존 그대로 |

- 기존 "기초생활보장 수급 여부", "차상위계층 여부" 삭제

## 4. 상담 운영정보 바꾸기

### 4-1. 선호 상담 방식

- 대면
- 전화
- 화상
- 기타(이메일, SNS 등)

### 4-2. 상담신청 유입경로

- 본인 신청
- 기관 추천
- 홈페이지/SNS
- 오프라인 홍보
- 기타

### 4-3. 연락 가능 시간

**연락 가능 요일**
- 평일
- 주말·공휴일

**연락 가능 시간대**
- 오전
- 오후
- 저녁

### 4-4. 연락 시 주의사항

- 기존 그대로

- 기존 "상담 방식" 삭제

## 5. 상담 신청 사유 및 필요 자원 연계 바꾸기

### 5-1. 상담신청 사유

- 경제·재무
- 부채
- 일자리·소득
- 주거
- 기타

### 5-2. 필요 자원 연계

- 상담신청 사유와 한 세트로 이어서 표시
- 건강·의료
- 심리·정서
- 법률·행정
- 가족
- 안전
- 기타

### 5-3. 신청 배경

- 기존 그대로

## 6. 칸 삭제

- 현재 어려움 관련 영역 (세부 질문 포함)
- 우선적으로 필요한 도움
- 상담 참여 여건
- 담당 실무자 판단 및 다음 단계

## 7. 글 칸 높이 자동 조절

- 대상: 이전에 받은 지원 / 강점과 도와줄 사람
- 글이 길어지면 칸이 아래로 늘어나게

---

## 바뀐 뒤 화면 순서

1. 상담 일시와 상담 방식 (추가)
2. 공적급여, 수급자 여부 (변경)
3. 상담 운영정보 (변경)
   - 선호 상담 방식
   - 상담신청 유입경로
   - 연락 가능 시간
   - 연락 시 주의사항
4. 상담 신청 사유 및 필요 자원 연계 (변경)
   - 상담신청 사유
   - 필요 자원 연계
   - 신청 배경
5. 이전에 받은 지원 (칸 높이 변경)
6. 강점과 도와줄 사람 (칸 높이 변경)
7. 전체 상담 목표
8. 수행할 과제
9. 다음에 물어볼 것
