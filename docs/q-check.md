## A. 판단이 필요한 것 — 제가 정하고 실행한 결정

되돌릴 수 있게 근거를 남겨 뒀습니다. **아니라고 하시면 되돌립니다.**

### A-1. 인테이크에 `수행할 과제`를 넣었다

- 어디: `인테이크 작성하기` 아래쪽, `다음에 물어볼 것` 바로 위
- 왜: 첫 상담에서도 약속("다음까지 서류 떼어 오기")이 나오는데 적을 자리가 없었다. 그러면 2회차 레일이 비어 `못 함 · 계속`을 누를 일이 생기지 않는다. 예행연습에서 대본 B 의 핵심 관찰이 아예 성립하지 않았다.
- 원래 `SPEC.md` §2-1 은 `promise` 를 상담 기록하기에서만 만든다고 적혀 있었다. 그 줄을 고쳤다.
- **볼 것**: 인테이크에서 과제를 적고 저장 → 1회차 `15초 다시보기`의 `확인할 과제`에 `1회차`로 뜨는지

### A-2. 인테이크 소절 제목에서 번호를 뗐다

- 전: `1-2. 공적급여·수급자 여부` … `3-2. 이전 지원 경험` … `3-4. 강점과 비공식 자원`
- 후: `공적급여·수급자 여부` … `이전 지원 경험` … `강점과 비공식 자원`
- 왜: 구 모듈 `2-1~2-5`가 국가 표준 영역으로 대체되고 `3-3`·`4-2`가 요구로 빠지면서 번호가 띄엄띄엄해졌다. 화면이 고장 난 것처럼 읽힌다. 번호는 `intake-questions.ts` 데이터에 정본 대조용으로 남아 있다.
- **볼 것**: 정본 문서와 대조할 때 번호가 없어서 불편한지

### A-3. 당사자 계정은 비밀번호가 맞아도 막았다

- `test3` 으로 로그인하면 `당사자는 로그인하지 않아요. 실무자가 보낸 링크와 코드로 열어요.`
- 왜: `GLOSSARY.md` §3 대로다. 당사자 열람은 P2 의 링크+코드이고 베타에는 없다. 계정만 만들어 두고 문을 닫았다.
- **볼 것**: 이 문구가 맞는지. 아예 계정을 만들지 말아야 한다면 말씀해 주세요

### A-4. 인테이크 말과 입력을 고쳤다 (2026-09-15 Q 지적)

| 전 | 후 |
|---|---|
| `이전 지원 경험` | `이전에 받은 지원` · 칸 이름 `다른 기관에서 받았거나 신청한 지원` |
| `강점과 비공식 자원` | `강점과 도와줄 사람` |
| 1·2순위 지원욕구 라디오 24개 | 드롭다운 2개, 1순위로 고른 값은 2순위에서 사라짐 |
| 주요 연락 가능 시간 · 참여 방해요인 · 선호 상담 방식 | 체크박스 (`복수 요인`·`혼합` 선택지 삭제) |
| `상담을 신청한 주된 사유는 무엇인가요?` | `상담을 신청한 사유` 체크박스 (`복합적인 어려움` 삭제) |
| 반복 입력(과제·질문·달라진 것)의 `추가` 버튼이 라벨 줄에 붙어 있던 것 | **입력칸과 버튼 한 행** (중심 어긋남 0px 실측) |

- `비공식자원`은 **표준 용어가 맞습니다**(공식/비공식 자원). 다만 그 칸이 실제로 받는 건 `도움을 요청할 사람`+`강점`이라 읽히는 말로 바꿨습니다. 표준어를 화면에 유지해야 하면 되돌립니다.
- **볼 것**: 인테이크에서 1순위를 고르면 2순위 목록에서 그게 빠지는지. 1순위를 2순위와 같은 값으로 바꾸면 2순위가 비워지는지

## B. 한 바퀴 — 10분

2. **당사자 목록** — `김민희` 검색. `2회차까지 기록 · 다음 ○월 ○일`
3. **당사자 등록** — 이름만 넣고 등록 → 인테이크로 바로 넘어가는지
4. **인테이크** — 어려움 영역에서 `경제`를 켜면 그 자리에 세부 질문이 열리는지(안 고른 영역은 안 열림). 아래에서 **과제**와 **질문**을 각각 한 줄씩 적고 저장
5. **상담 일정 등록** — 일시만 넣고 등록. `종결 상담` 체크상자가 보이는지
6. **15초 다시보기** — 방금 적은 과제와 질문이 `1회차`를 달고 올라왔는지
7. **상담 기록하기** — 왼쪽 레일의 과제에 `못 함 · 계속`을 누르고, **질문에는 아무것도 누르지 말고** 상담 내용만 적어 저장
8. **다시 15초 다시보기** — 안 누른 질문이 `지난 회차 미확인`을 달고 다시 올라왔는지 ← **이 제품의 핵심**
9. **당사자 정보** — 탭 4개(회차별 요약·15초 다시보기·목표·정보). 회차별 요약에서 `원문 보기`
10. **상담 종결** — `정보` 탭 아래 버튼 → 미완료 과제가 `○회차에서 시작`으로 보이는지 → 사유 고르고 확정 → 회차별 요약에 **번호 없는** 종결 항목이 붙는지
