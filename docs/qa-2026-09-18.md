# 사용자 여정 중간 점검 (2026-09-18)

내일 최종 완성 전 중간 점검. 스모크·드라이런·E2E 를 **사이트 도착 → 기관 첫 가입(온보딩) → 실무자 초대·가입 → 당사자 등록 → 인테이크 → 상담 일정 → 상담 기록 → 회차별 요약·AI 정리 → 상담 종결** 순으로 밟았다. 기획·디자인·개발 세 역할이 각각 한 바퀴 돌고, 고칠 것은 이 브랜치(`qa/journey-2026-09-18`)에서 고쳤다. **PR 은 올리지 않았다.** 비개발자가 만드는 제품이라 완벽주의 대신 "내일 실무자가 실제로 막히는가"를 기준으로 삼았다.

## 미룬 것 (Q 판단)

- 녹음만 딴 회차(수기 미작성)가 있는데 다시 `상담 기록하기`로 저장하면 회차가 둘로 갈라진다 — `ensureSession` 이 `planned` 만 재사용. 이어 쓰는 길은 `회차별 요약 › 수정`뿐. 고치려면 "미작성 회차가 있으면 그 회차를 연다"는 규칙이 SPEC 에 필요.
- 인테이크에 자유 메모 칸이 `신청 배경` 하나 — 월세·계약 만료 같은 정량 메모가 몰린다. `참고 메모` 문항 추가는 정본(intake-questions) 결정.
- 회차 정보 줄 `수기 3 전사 승인 0` 의 어휘·단위(`기록 3회, 전사 확인 0건`) — GLOSSARY 결정.
- 설정 › 시스템의 `관리자 전용` 카드가 빈 카드처럼 보임(P2).
- `settings.tsx` 의 다른 판 9곳도 `void getX().then(setX)` 패턴이라 실패 시 `불러오는 중`에 멈춘다(배너는 뜸). 이번엔 연결 판만 고침.
